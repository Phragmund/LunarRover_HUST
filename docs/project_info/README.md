## 项目介绍

主题：月球熔岩洞自主探测机器人

我们需要制作一辆全自动的六轮摇臂结构的月球车机器人，完成比赛场地内的科学目标采集任务。机器人全自动运行，不得使用遥控远程控制。目前我们的机器人大约是650*500mm(按照目前的urdf来即可，后续会导入更加精确完整的urdf)。比赛场地模拟月球熔岩洞环境，场地由石膏或混凝土浇筑而成，内部模拟月球熔岩管道环境，由错综复杂的岩石通道组成，通道直径约1.5m，通道壁模拟岩洞岩石质感，通道底部铺有沙子作为底土，底土中均匀埋着一些岩石，岩石部分露出地面作为障碍物，露出部分至高不超过100mm。这个浇筑的岩洞有一个入口，车辆会从外部走入口进入熔岩管环境。入口处有约6°的1m下坡路段。月球机器人进入熔岩管区域后，需要自动扫描建图，自动导航，避开难以跨越的地面障碍物（前文提到障碍物至高100mm，车轮能跨越的约60mm）。探索熔岩管内环境时，还需要搜索熔岩管内的科学目标，科学目标为5×5×5cm³的方木块，以及特殊形状的人造物（形状各异的矿石模型），颜色与场地区别较大。科学目标会随机放置在沙土地面上以及岩壁上（非嵌入，部分岩壁形似平台，可以放置小物块）。机器人需要自主寻找小物块，并使用机械臂夹取物块放置在车上，如是在岩洞中收集探索，直到决策算法发出返回指令后，月球车开始返回入口并回到启动平台，将收集到的物块放入启动平台旁一块500×500mm的区域内，即视为任务完成。从机器人启动到放置完所有物块停止计时，总共600s，超时则机器人立即断电，并按当前完成的任务计算部分分数。以上即为本项目的比赛任务背景。这份背景介绍综合了大部分信息，比较简洁且呈现了所有重要信息。我同时会给一些原始资料文件给你作为参考，但我刚刚介绍的内容应该特别注意（都是重点），原始资料仅供参考。

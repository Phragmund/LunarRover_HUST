# Livox Mid-360 Official Files Index

The official binary/manual files themselves are **not committed** to this
repository. Download them from the links below when they are needed.

| File | Purpose | Notes |
| --- | --- | --- |
| `Livox_Mid-360_User_Manual_EN.pdf` | Wiring, power, IP, connector details | Required reading before first power-on |
| `Livox_Mid-360_Quick_Start_Guide_multi.pdf` | Short official setup guide | Includes Chinese pages |
| `Livox_Viewer_2_User_Manual_EN_v1.2.pdf` | Viewer 2 usage, discovery, capture, firmware upgrade | |
| `LivoxViewer2_for_Ubuntu_v2.3.0.zip` | Official Ubuntu Viewer 2 package | Unpack before use |
| `Livox_Mid-360_Release_Notes_EN.pdf` | Firmware release notes | |
| `LIVOX_MID360_FW_v13.18.0244.bin` | Latest firmware downloaded on 2026-08-15 | Do not upgrade until basic function is verified |

Official links:

- Mid-360 downloads: <https://www.livoxtech.com/mid-360/downloads>
- Livox-SDK2: <https://github.com/Livox-SDK/Livox-SDK2>
- Livox ROS Driver 2: <https://github.com/Livox-SDK/livox_ros_driver2>
- Mid-360 wiki: <https://livox-wiki-en.readthedocs.io/en/latest/tutorials/new_product/mid360/mid360.html>

Suggested local location for downloaded files:

```text
docs/vendor/livox_mid360/
```

That path is ignored by git and can be recreated on any machine that needs the
real-hardware test procedure in `docs/mid360_real_lidar_test.md`.

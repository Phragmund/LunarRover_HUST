### 第二组采样方案

第二组可以把底盘移动到新的位置，再重新采样。关键是第二组要单独求解，不能把两个底盘位置的原始行直接拼成一次 `calibrateHandEye`：每一组内部仍需保持 ChArUco 板相对该组 `base_link` 固定即可。

两组分别得到 `tool_T_camera` 后，先比较：

- 平移差和旋转轴角差；
- 各组内部的板位残差；
- 是否存在某一组整体偏移或离群样本。

若两组结果一致，可将平移做加权平均，并用 SO(3) 的旋转平均（不能直接平均欧拉角）形成新的候选 TF。后续第三组可作为独立复核。J5 在本项目中是夹爪开合关节，不需要为了标定刻意改变；应主要改变 J1～J4，确保相机姿态和视角有足够变化。

只有跨组解收敛并完成独立板位/抓取验证后，才执行：

```bash
python3 tools/handeye_calibration_registry.py activate <new-profile-id>
bash scripts/restart_handeye_tf.sh
```

抓取经验补偿（J1/J4、前伸、竖直下降）与本外参 campaign 分开记录，不因本次解算自动改动。
